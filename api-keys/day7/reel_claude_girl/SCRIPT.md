# "A më do?": Reel script (DRAFT v2, awaiting approval)

Characters: **ANA**, a programmer girl, about 24, tired, at 2 a.m. **CLAUDE**, a small terracotta-orange cube robot with short legs, two dot eyes and an antenna shaped like a little spark.
Place: a dark room at night, a desk with glowing screens full of code, a large window with the lights of Tirana behind it.
