# Shot list: "A më do?" (low-poly, 9:16, ~52s)

Assets: `assets/ana_sheet.png`, `assets/claude_sheet.png`, `assets/room.png` (Claude always on the desk, left of the laptop; Ana in the chair on the right).
Each shot = 1 keyframe (image) → 1 Omni clip with the Albanian line. One speaker per shot (clean lip-sync). Claude has no mouth: his line is voice only, his antenna spark pulses while he talks.
Subtitles and the chat bubble (shot 7) are added in post: white = Ana, orange = Claude.
